# 💎 Crystal 空间相机：把照片变成 3D 记忆 📸

**Crystal Spatial Camera** 是一款把普通照片变成可旋转、可缩放 3D 记忆的 iOS 应用。你只需拍几张照片，Crystal 就会为你生成一个属于你自己的 3D 记忆 —— 像一次「空间捕捉」，让你可以从不同角度重新走进那个瞬间。🌟

它非常适合保存有意义的物品、旅行回忆、日常瞬间、礼物和家庭聚会，用更生动、更有空间感的方式，把重要的记忆珍藏起来。

## 🌟 主要功能

- **📸 拍照生成 3D 记忆**
  - 只需拍摄几张照片，Crystal 就能为你生成个人 3D 记忆。

- **🖼️ 相册模式浏览**
  - 在相册模式中浏览你所有的 3D 记忆，随时回看。

- **🔄 自由旋转与缩放**
  - 拖拽即可旋转，捏合即可缩放，从任意角度自由观察 3D 内容。

- **🎞️ 导出分享**
  - 将 3D 记忆导出为**视频**或 **Live Photo**，轻松分享每一个珍贵瞬间。

## ✨ 为什么选择 Crystal

传统相册里存的是一张平面照片，而 Crystal 存的是一段可以进入和环视的**空间记忆**。相比一张固定角度的图片，3D 记忆能承载更多细节、更多沉浸感，也更有分享的价值。

无论是心爱的手办、旅途中的风景，还是家人团聚的一刻，Crystal 都能帮你把它们变成更立体、更鲜活的回忆。

> Memories, held in Crystal. 💎
> 把记忆，珍藏在 Crystal 里。

## 🇯🇵 日本語

**Crystal Spatial Camera（クリスタル空間カメラ）** は、あなたの写真を 3D の思い出に変える iOS アプリです。

大切な物、旅の思い出、日常のワンシーン、贈り物、家族の集まりなど、大切な記憶をより鮮やかで立体的なかたちで残すのに最適です。

**主な機能**

- 📸 写真を撮って 3D メモリーを作成
- 🖼️ アルバムモードですべての思い出を閲覧
- 🔄 回転・拡大で 3D コンテンツを自由に鑑賞
- 🎞️ ビデオや Live Photo として書き出し

*Memories, held in Crystal.* 💎
*思い出を、Crystal の中に。*
